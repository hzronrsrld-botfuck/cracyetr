# Unity karakter dosyaları

Bu depoda Ch36 tabanlı, Mixamo iskeletli Unity karakter paketleri bulunur.

- `downloads/ERKEK_KARAKTERLER_UNITY.zip`: savaşçı, ninja, şaman ve Sura
- `downloads/KADIN_KARAKTERLER_UNITY.zip`: savaşçı, ninja, şaman ve Sura
- Küçük savaşçı paketleri ayrıca verilmiştir.

Unity'de FBX dosyasının **Rig** bölümünden `Animation Type = Humanoid` ve
`Avatar Definition = Create From This Model` seçin.
